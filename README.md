Firefox, бодит touch төхөөрөмж, дэлгэц уншигч болон зэрэгцээ хэрэглэгчийг шалгаагүй учраас дараагийн charter-ийг браузер хоорондын ажиллагаа, хүртээмж, зэрэгцээ үйлдэлд чиглүүлнэ.

Өнгөний аюулын дохио, урт текстийн layout, Монгол бичвэрийн чанарыг хүний нүдээр үнэлэх нь тустай боловч computed-style, screenshot, Unicode assertion ашиглавал эдгээрийг ч автоматжуулж болох тул зөвхөн хүний нүдээр л олдоно гэж дүгнээгүй.
