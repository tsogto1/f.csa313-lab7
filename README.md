## Одоогийн төлөв

Session-ээс өмнөх [charter](charter.md)-ийг бэлдсэн.
Багшийн «Уншлагын жагсаалт» v2.0 `app.js` файл одоогоор ирээгүй тул
60 минутын session эхлээгүй, согог болон түүний нотолгоо бүртгээгүй.
Энэ репозиторь одоогоор лабораторийн бүрэн гүйцэтгэл биш.

## Тестлэх апп

Аппын эх сурвалж: Teams → Files → Class Materials → Labs → Lab07,
эсвэл лабораторийн Assignment-ийн багшийн хавсралт.
`app.js`-ийг энэ репозиторийн үндсэн хавтаст локал байрлуулж ажиллуулна:

```sh
node app.js
```

Браузераар `http://localhost:3000` хаягт орно.
Апп өгөгдлөө санах ойд хадгалдаг тул процессыг зогсоож дахин асаахад
анхны 3 номын төлөвт буцна. Дахин гаргах алхам бүрийг энэ төлөвөөс шалгана.
Аппын эх кодыг согог хайх зорилгоор уншихгүй, өөрчлөхгүй.
`app.js` нь `.gitignore`-д орсон; багшийн файлыг тайлангийн хэсэг болгон
GitHub-д нийтлэхгүй.

## Төлөвлөсөн гүйцэтгэл

1. Charter-ийг session эхлэхээс өмнө commit, push хийх.
2. Багшийн апп дээр бодит 60 минутын session хийж, цагтай түүхий
   тэмдэглэл болон зураг/API нотолгоо цуглуулах.
3. `session-report.md`-ийг бодит эхлэх/дуусах цаг, саад, цагийн
   задаргаатай нь тусдаа commit хийх.
4. Дор хаяж 3 өөр согогийг шинэ апп дээр давтан баталж, `bugs/`-д тайлагнах;
   дор хаяж нэг нь API/өгөгдлийн түвшний согог байна.
5. Согогийн тайлан, нотолгоо, 8–10 өгүүлбэрийн debrief-ийг бодит үр дүнд
   үндэслэн нэмээд тусдаа commit, push хийх.
6. Шинэ хавтсанд clone хийж тайлангийн алхам, хавсралт, холбоосуудыг шалгах.

Session болон нотолгоо үүссэний дараа дүгнэлтийг энэ README-ийн төгсгөлд нэмнэ.
