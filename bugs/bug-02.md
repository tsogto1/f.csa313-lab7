# BUG-02: Хүснэгтийн оныг 1971-ийн оронд 1,971 гэж дүрслэнэ

Орчин: Уншлагын жагсаалт v2.0; Node.js v20.19.2; Chromium 154.0.8037.57 (headless); Debian GNU/Linux 13.6 x86_64; 2026-10-20; Asia/Ulaanbaatar. UI viewport 1440 × 1000, өөрөөр заагаагүй бол.

Урьдчилсан нөхцөл: Багшийн өөрчлөгдөөгүй app.js файлыг репозиторийн үндсэн хавтаст байрлуулсан. Өөрийн өмнөх app процессыг зогсоож, `node app.js`-ийг шинээр асаасан; анхны «Тунгалаг Тамир», «Clean Code», «The Pragmatic Programmer» гэсэн 3 номтой. UI-д `http://localhost:3000`-г нээнэ. Хэрэв Node-ийн олон хувилбартай бол `node -v` нь v20.19.2 гэдгийг эхлээд батална.

## Дахин гаргах алхам

1. Шинэ аппын үндсэн хуудсыг нээнэ.
2. «Тунгалаг Тамир» номын «Он» нүдийг уншина.
3. Бусад хоёр номын оны нүдтэй харьцуулна.

Хүлээгдэж байсан: «Он нь ... хүснэгтэд энгийн тоогоор (жишээ нь 1999) харагдана»: 1971, 2008, 1999 гэж таслалгүй байна.

Бодит үр дүн: Онуудад мянгатын таслал орсон: «1,971», «2,008», «1,999». API baseline дахь 1971/2008/1999 тоонуудтай харьцуулахад энэ нь UI дүрслэлийн зөрчил. Эцсийн 25 replay тойрогт давтагдсан.

Ноцтой байдал: **Cosmetic — утгыг ойлгож болох боловч оны дүрслэлийн тодорхой шаардлагыг зөрчинө.**
