# BUG-03: Устгах товч улаан биш ногоон өнгөтэй байна

Орчин: Уншлагын жагсаалт v2.0; Node.js v20.19.2; Chromium 154.0.8037.57 (headless); Debian GNU/Linux 13.6 x86_64; 2026-10-20; Asia/Ulaanbaatar. UI viewport 1440 × 1000, өөрөөр заагаагүй бол.

Урьдчилсан нөхцөл: Багшийн өөрчлөгдөөгүй app.js файлыг репозиторийн үндсэн хавтаст байрлуулсан. Өөрийн өмнөх app процессыг зогсоож, `node app.js`-ийг шинээр асаасан; анхны «Тунгалаг Тамир», «Clean Code», «The Pragmatic Programmer» гэсэн 3 номтой. UI-д `http://localhost:3000`-г нээнэ. Хэрэв Node-ийн олон хувилбартай бол `node -v` нь v20.19.2 гэдгийг эхлээд батална.

## Дахин гаргах алхам

1. Шинэ аппын үндсэн хуудсыг нээнэ.
2. Хүснэгтийн мөр бүрийн «Устгах» товчийг ажиглана.
3. Браузерын computed style-оор товчны background-color-ийг шалгана; аппын эх кодыг унших шаардлагагүй.

Хүлээгдэж байсан: «Аюултай үйлдлийн товч (Устгах) улаан өнгөтэй» байна.

Бодит үр дүн: Бүх «Устгах» товч ногоон. Computed background-color нь `rgb(44, 122, 75)`; foreground нь `rgb(255, 255, 255)`. Эцсийн 25 replay тойрогт background өнгө ижил байсан.

Ноцтой байдал: **Minor — буруу өнгө нь устгах үйлдлийг аюулгүй/эерэг мэт харагдуулж, хэрэглэгчийн андууралд хүргэж болно.**
