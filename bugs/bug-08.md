# BUG-08: «Нэмэx» товчны төгсгөлийн үсэг Cyrillic х биш Latin x байна

Орчин: Уншлагын жагсаалт v2.0; Node.js v20.19.2; Chromium 154.0.8037.57 (headless); Debian GNU/Linux 13.6 x86_64; 2026-10-20; Asia/Ulaanbaatar. UI viewport 1440 × 1000, өөрөөр заагаагүй бол.

Урьдчилсан нөхцөл: Багшийн өөрчлөгдөөгүй app.js файлыг репозиторийн үндсэн хавтаст байрлуулсан. Өөрийн өмнөх app процессыг зогсоож, `node app.js`-ийг шинээр асаасан; анхны «Тунгалаг Тамир», «Clean Code», «The Pragmatic Programmer» гэсэн 3 номтой. UI-д `http://localhost:3000`-г нээнэ. Хэрэв Node-ийн олон хувилбартай бол `node -v` нь v20.19.2 гэдгийг эхлээд батална.

## Дахин гаргах алхам

1. Шинэ аппын нэмэх товчны текстийг шалгана.
2. Шаардлагатай бол browser console-д `document.querySelector("button").textContent`-ийг уншина; энэ нь runtime DOM шалгалт, app.js-ийн эх код биш.
3. Текстийн сүүлийн тэмдэгтийн Unicode кодыг зөв «Нэмэх» бичвэртэй харьцуулна.

Хүлээгдэж байсан: «Текстүүд үсгийн алдаагүй»: нэмэх товч «Нэмэх» гэж бичигдэж сүүлийн үсэг Cyrillic х, U+0445 байна.

Бодит үр дүн: Текст «Нэмэx», сүүлийн тэмдэгт Latin x буюу U+0078. `evidence/bug-08-label.json` нь бодит болон хүлээгдсэн codepoint-уудыг хадгалсан. Зураг дээр үсгүүд төстэй харагдана; BUG-08 зураг нь анхны baseline screenshot-ийн өөрчлөлтгүй хуулбар.

Ноцтой байдал: **Cosmetic — үйлдэл ажиллах боловч харагдах бичвэр Монгол хэлний зөв бичлэгийн шаардлага зөрчинө.**
